# הגשה דרך טופס Google Forms

מסלול האוטומציה: עסק חדש ממלא טופס בגוגל → Apps Script רץ אוטומטית → נוצר Pull Request בריפו → אתה בודק ומאשר → העסק מתפרסם.

המדריך הזה מכיל את כל מה שצריך לעשות פעם אחת. הזמן הכולל: כ-10 דקות.

---

## שלב 1 — צור Personal Access Token ב-GitHub

ה-Apps Script צריך הרשאה לכתוב לריפו.

1. כנס ל-https://github.com/settings/personal-access-tokens/new
2. **Token name:** `community-plus-form`
3. **Expiration:** 90 ימים (או יותר — תצטרך לחדש אחרי שיפוג)
4. **Repository access:** Only select repositories → בחר `community-plus`
5. **Repository permissions:**
   - **Contents:** Read and write
   - **Pull requests:** Read and write
   - שאר ההרשאות: השאר על No access
6. לחץ **Generate token**
7. **שמור את הטוקן בצד** (מתחיל ב-`github_pat_...`). זה יוצג רק פעם אחת.

## שלב 2 — צור את הטופס בגוגל

1. כנס ל-https://forms.new
2. שם הטופס: **הוספת עסק לקהילה+**
3. תיאור: `מלאו את הפרטים והעסק שלכם יישלח לאישור.`
4. הוסף את השדות הבאים — **חשוב שהשם של כל שדה יהיה זהה בדיוק לרשימה למטה** (ה-Script מחפש לפי שם השדה):

| מספר | שם השדה | סוג | חובה? |
|---|---|---|---|
| 1 | `שם העסק` | תשובה קצרה | ✅ |
| 2 | `קטגוריה` | תשובה קצרה (או רשימה נפתחת) | ✅ |
| 3 | `תיאור קצר` | תשובה קצרה | ✅ |
| 4 | `תגיות` | תשובה קצרה | ✅ |
| 5 | `קישור לתמונה` | תשובה קצרה | אופציונלי |
| 6 | `תיאור מלא` | פסקה | אופציונלי |
| 7 | `טלפון` | תשובה קצרה | אופציונלי |
| 8 | `אימייל` | תשובה קצרה | אופציונלי |
| 9 | `אתר אינטרנט` | תשובה קצרה | אופציונלי |
| 10 | `כתובת` | תשובה קצרה | אופציונלי |

**טיפים לטופס:**
- לשדה `תגיות` הוסף תיאור: `תגיות מופרדות בפסיקים, למשל: מאפייה, אוכל, משפחתי`
- לשדה `קישור לתמונה` הוסף תיאור: `URL ישיר לתמונה. אפשר להעלות חינם ל-imgur.com או postimages.org`
- לשדה `קטגוריה` רצוי רשימה נפתחת עם הקטגוריות הקיימות באתר

## שלב 3 — הוסף את ה-Apps Script

1. בטופס הפתוח, לחץ על שלוש הנקודות בפינה הימנית-עליונה → **Script editor** (או **עורך התסריט**).
2. תיפתח כרטיסיית Apps Script. מחק את כל מה שיש בקובץ `Code.gs` והדבק במקום את **כל התוכן** של [`form-to-github.gs`](form-to-github.gs).
3. לחץ על **שמור** (אייקון הדיסקט) או `Ctrl/Cmd + S`.
4. **הוסף את ה-Token** ל-Script Properties:
   - בעורך, לחץ על **Project Settings** (גלגל שיניים בצד שמאל)
   - גלול ל-**Script properties** → **Add script property**
   - **Property:** `GITHUB_TOKEN`
   - **Value:** הדבק את הטוקן ששמרת בשלב 1
   - לחץ **Save script properties**

## שלב 4 — הוסף Trigger אוטומטי על הגשת טופס

1. בעורך ה-Script, לחץ על **Triggers** (אייקון השעון בצד שמאל).
2. **Add Trigger** (כפתור כחול בפינה הימנית-תחתונה).
3. הגדר:
   - **Choose which function to run:** `onFormSubmit`
   - **Choose which deployment should run:** `Head`
   - **Select event source:** `From form`
   - **Select event type:** `On form submit`
4. **Save**. גוגל תבקש הרשאות — אשר אותן (זה מאפשר ל-Script לקרוא הגשות ולשלוח בקשות ל-GitHub).

---

## שלב 5 — בדיקה

יש שתי דרכים לבדוק:

**אפשרות א׳ — הרץ את `testRun` ידנית:**
1. בעורך ה-Script, ב-dropdown של הפונקציות, בחר `testRun`.
2. לחץ **Run**.
3. אם הכל הוגדר נכון, יווצר PR חדש בריפו עם הכותרת "הוספת עסק: בדיקת טופס".
4. סגור את ה-PR אחרי שראית שזה עובד (אל תמזג אותו).

**אפשרות ב׳ — מלא הגשה אמיתית בטופס:**
1. פתח את ה-URL של הטופס (כפתור **Send** → אייקון הקישור).
2. מלא את השדות והגש.
3. בודק את הריפו — אמור להופיע PR חדש.

---

## שלב 6 — חבר את הטופס לאתר

עכשיו שהטופס עובד, הוסף את ה-URL שלו ל-`_config.yml` בריפו כדי שיופיע כפתור "הוסף את העסק שלך" באתר:

```yaml
form_url: "https://forms.gle/..."
```

(החלף ב-URL הקצר של הטופס — מתקבל מהכפתור **Send** → אייקון השרשרת → **Shorten URL**.)

דחוף ל-GitHub. תוך כדקה הכפתור יופיע באתר.

---

## איך זה עובד בשימוש שוטף

1. מגיש ממלא טופס.
2. תוך שניות נפתח PR בריפו עם קובץ `.md` חדש תחת `_businesses/`.
3. אתה מקבל התראה ב-GitHub (או באימייל אם הפעלת).
4. בודק את התוכן והתמונה ב-PR.
5. אם הכל בסדר — `Merge`. אחרת — `Close`.
6. תוך דקה ה-Action של GitHub Pages בונה מחדש את האתר עם העסק החדש.

## פתרון בעיות

- **אין PR אחרי הגשה:** בדוק את ה-Logs של ה-Script (`Executions` באייקון בצד שמאל). השגיאה הנפוצה ביותר היא `GITHUB_TOKEN לא מוגדר` או טוקן שפג.
- **שגיאה 401/403 ב-API:** הטוקן פג או אין לו הרשאות מתאימות. צור טוקן חדש ועדכן ב-Script Properties.
- **שגיאה 422 ביצירת branch:** ייתכן ש-branch באותו שם כבר קיים. ה-slug כולל timestamp אז זה נדיר — אבל אם קורה, זה יעבור בפעם הבאה.
- **שמות שדות לא תואמים:** אם שינית את השמות בטופס, עדכן את האובייקט `FIELD` בראש הקוד של ה-Script.
