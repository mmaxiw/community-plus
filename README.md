# קהילה+ (Community Plus)

מדריך לעסקים ובעלי מקצוע מקומיים, מאוחסן בחינם ב-GitHub Pages.

**אתר חי:** https://mmaxiw.github.io/community-plus/

כל עסק הוא קובץ Markdown בודד עם תמונה, תיאור, פרטי קשר ותגיות. באתר חיפוש חופשי וסינון לפי תגיות.

---

## איך מוסיפים עסק או בעל מקצוע

1. צרו קובץ חדש בתיקייה `_businesses/`. תנו לו שם באנגלית עם מקפים — לדוגמה `falafel-eli.md`.
2. העתיקו את התבנית הבאה לתוך הקובץ:

   ```yaml
   ---
   name: פלאפל אלי
   category: אוכל ומשקאות
   image: https://example.com/path/to/photo.jpg
   tags: [פלאפל, אוכל, מסעדה, משפחתי]
   description: משפט סיכום שמופיע על כרטיס העסק.
   contact:
     phone: "050-000-0000"
     email: hello@example.com
     website: https://example.com
     address: "רחוב הרצל 12, תל אביב"
   ---

   תיאור ארוך כאן. אפשר להשתמש ב-Markdown:

   - נקודות
   - **מודגש** ו-*נטוי*
   - [קישורים](https://example.com)

   ## כותרות משנה
   ```

3. שמרו ודחפו (push), או ערכו ישירות ב-github.com. האתר ייבנה מחדש אוטומטית תוך כדקה.

כל השדות חוץ מ-`name` הם אופציונליים, אבל מומלץ למלא לפחות `image`, `tags` ו-`description` — כך החיפוש יעבוד טוב יותר והכרטיס יראה מלא.

## אחסון תמונות

שתי אפשרויות:

- **כתובת חיצונית** (הכי קל): הדביקו URL ישיר של תמונה לשדה `image:`. שירותים חינמיים:
  - [imgur.com](https://imgur.com) — חינם, ללא הרשמה
  - [postimages.org](https://postimages.org) — חינם, ללא הרשמה
- **בתוך הריפו**: שמרו את התמונה ב-`assets/images/` ושימו `image: /assets/images/photo.jpg`.

גודל מומלץ: 800×500 או יותר, פורמט אופקי.

## תגיות

הוסיפו את `tags:` כמערך YAML:

```yaml
tags: [אוכל, משפחתי, ללא-גלוטן]
```

תגיות מופיעות על כל עסק כפתורים. לחיצה על תגית מסננת את הדף הראשי לעסקים עם אותה תגית. אפשר ללחוץ על כמה תגיות יחד כדי לצמצם.

---

## תפריט קיצורי דרך (סרגל הצד)

סרגל הצד הוא תפריט הניתן להתאמה אישית — תוכלו להוסיף, לשנות ולסדר כפתורים בלי לגעת ב-HTML או ב-CSS. כל ההגדרות נמצאות בקובץ אחד: [`_data/menu.yml`](_data/menu.yml).

מבנה הקובץ:

```yaml
groups:
  - title: שם הקבוצה
    items:
      - label: טקסט הכפתור
        tag: שם-תגית      # סינון לפי תגית מדויקת
      - label: טקסט הכפתור
        q: מילת חיפוש    # חיפוש חופשי (טקסט/קטגוריה)
```

- כל פריט הוא או `tag:` (סינון לפי תגית מדויקת) או `q:` (חיפוש חופשי).
- שינוי בקובץ → דחיפה ל-GitHub → האתר נבנה מחדש תוך כדקה.
- כפתור פעיל (תואם לסינון הנוכחי) מודגש אוטומטית בכחול.
- בנייד התפריט עובר אוטומטית למעלה כשורת כפתורים אופקית.

## חיפוש

תיבת החיפוש מחפשת ב:

- שם העסק
- קטגוריה
- תיאור
- תגיות

ה-URL מתעדכן בזמן חיפוש, כך שאפשר לשתף קישור עם סינון פעיל.

## טכנולוגיה

- **אתר סטטי:** [Jekyll](https://jekyllrb.com/), נבנה ומאוחסן בחינם ב-GitHub Pages.
- **ללא צורך ב-build מקומי.** דחפו את הקובץ — GitHub יבנה את האתר.
- **ללא בסיס נתונים.** כל קובץ `.md` הוא עסק.
- **ללא שירותים חיצוניים.** החיפוש הוא JavaScript בצד הלקוח.

לתצוגה מקדימה מקומית (אופציונלי, לא נדרש לפרסום):

```bash
bundle install
bundle exec jekyll serve
```

## רוצים להופיע ברשימה?

האפשרות הקלה — מלאו את הטופס באתר (אם הוקם):

1. לחצו על "הוסיפו את העסק שלכם" בכותרת.
2. ההגשה נפתחת אוטומטית כ-Pull Request לבדיקה.

האפשרות הידנית:

1. עשו fork לריפו, הוסיפו קובץ `.md` ב-`_businesses/`, ופתחו pull request.
2. או פתחו issue עם הפרטים שלכם.
